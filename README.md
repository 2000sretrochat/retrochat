# Razzle Social

Source snapshot of the Razzle Social preview. It includes the web UI and the Worker that serves it.

Use Node.js 22 or newer. Run npm run build, npm run validate, and node scripts/check-worker.mjs to check the source. Run npm run dev for a local preview.

Live preview: https://social-chat-preview-jn.fair-mink-5216.chatgpt.site/

Social friendships and posts are browser-local preview data. Live chat is a separate service.
